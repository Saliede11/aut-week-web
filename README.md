# برنامه هفتگی — نسخه وب

این پوشه خودش را روی GitHub Pages می‌سازد و منتشر می‌کند (فایل `.github/workflows/pages.yml`).
هیچ رمز یا داده شخصی در آن نیست. داده‌ها فقط در مرورگر هر کاربر می‌مانند.

- `src/index.html` و `src/sync.js` همان رابط و کد خواندن اپ اندروید هستند (کپی).
- `src/web-adapter.js` رابط وب را به همان `Native` وصل می‌کند.
- `src/bridge-glue.js` + `sync.js` = «میان‌بر اتصال» که داخل صفحه سایت رزرو اجرا می‌شود.
- `build.py` فونت را می‌گیرد و میان‌بر را با هش SRI می‌بندد.
